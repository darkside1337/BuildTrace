# BuildTrace Trace logo assets

Generated with ChatGPT's built-in ImageGen from the approved Trace concept.

- `buildtrace-trace-mark-navy.png`: transparent standalone BT monogram, 1254 × 1254.
- `buildtrace-trace-horizontal-navy.png`: transparent horizontal mark and serif wordmark, 2172 × 724.
- `buildtrace-trace-app-icon.png`: opaque white-on-navy square app icon, 1254 × 1254.

These are raster PNG masters, not vector artwork. Preserve aspect ratios. The intended palette is navy `#173e69` and warm paper `#f4f1e9`.

## Generation brief

1. Extract the approved Trace monogram into a standalone navy asset on transparency, preserving the routed B, T stem, sweeping top stroke, and detached square endpoint.
2. Produce the approved horizontal logo with that mark and the exact serif wordmark `BuildTrace`, on transparency.
3. Produce a compact white version of the approved monogram on an opaque navy square for app-icon use.

Transparent white attempts with edge artifacts were rejected and are not part of this asset set.

## Provider marks

The sign-in buttons use the official static PNG marks from [GitHub](https://github.githubassets.com/images/modules/logos_page/GitHub-Mark.png) and [Google Identity](https://developers.google.com/identity/images/g-logo.png). The GitHub mark has a white square background, so its button uses the matching paper surface.
